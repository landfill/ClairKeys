## Local review round 1 — 3 findings, all fixed before PR creation

1. **HIGH — concurrent 3GB JVMs on a 4GB VM.** Fixed with
   `AUDIVERIS_MAX_CONCURRENCY=1` and an application-level semaphore in the shared processor
   instance. A two-request behavior test records a maximum of one active conversion.
2. **MEDIUM — multiple `.mxl` files silently truncated.** Fixed by explicit failure when more than
   one MusicXML export is present. Combining separate exports was rejected because silently choosing
   or concatenating them has no established product contract.
3. **LOW — test names overstated runtime evidence.** Renamed to behavior/static deployment
   contracts; README and validation explicitly state that Docker/Fly were not run.

Follow-up review: zero blockers, all three findings confirmed resolved.

## Hosted review and local review round 2

CodeRabbit reviewed `8f21c2b` and found two valid subprocess-lifecycle gaps:

1. **CRITICAL — no conversion timeout could permanently occupy the sole semaphore slot.**
2. **MINOR — installation validation shared the same unbounded `communicate()` call.**

Both are fixed in `4613e08` with a configurable 900-second conversion timeout, a 30-second maximum
validation timeout, and kill/reap cleanup before the semaphore is released. A subsequent
independent review found one additional **HIGH** cancellation path: cancelling the caller released
the semaphore while leaving Audiveris alive. A regression failed before the fix; timeout and
`asyncio.CancelledError` now share the same kill/wait cleanup. The final independent review found
zero actionable issues and verified timeout and cancellation with a real local subprocess
(`returncode=-9`).

CodeRabbit also questioned whether the packaged launcher reads `Audiveris.cfg`. Direct inspection of
the checksum-pinned 5.11.0 `.deb` established that this is the jpackage launcher's actual
configuration. The image now fails its build unless the exact `java-options=-Xmx3G` line exists.
CodeRabbit accepted that package evidence, withdrew the finding, and resolved the thread. Optional
package installation is also disabled with `--no-install-recommends`.

The `defusedxml` nit was not adopted: project rules forbid a new dependency without explicit
request, and the parsed file is a local Audiveris artifact rather than a directly uploaded XML
document. The existing container path checks remain.
