## Local review round 1 — 3 findings, all fixed before PR creation

1. **HIGH — concurrent 3GB JVMs on a 4GB VM.** Fixed with
   `AUDIVERIS_MAX_CONCURRENCY=1` and an application-level semaphore in the shared processor
   instance. A two-request behavior test records a maximum of one active conversion.
2. **MEDIUM — multiple `.mxl` files silently truncated.** Fixed by explicit failure when more than
   one MusicXML export is present. Combining separate exports was rejected because silently choosing
   or concatenating them has no established product contract.
3. **LOW — test names overstated runtime evidence.** Renamed to behavior/static deployment
   contracts; README and validation explicitly state that Docker/Fly were not run.

Follow-up review: zero blockers, all three findings confirmed resolved.
