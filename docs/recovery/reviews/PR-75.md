## 핵심 설계

회전 조건을 `engaged && (pointer: coarse) && (orientation: portrait)` **한 줄**로 둔다.
Android의 `lock()` 성공은 화면을 실제 가로로 만들어 portrait 질의를 스스로 종료시키므로,
**이슈가 요구한 "이중 회전 해제"가 별도 분기 없이 같은 식에서 나온다.** 사용자가 직접 기기를
돌린 경우도 동일하게 처리된다.

iOS 판별은 `typeof screen.orientation?.lock === 'function'`으로만 한다 — iOS는 인터페이스
자체는 Safari 16.4+로 제공한다. 방향 요청은 재생 클릭 핸들러에서 **동기적으로** 발사한다
(`play()`가 await하는 동안 fullscreen의 transient activation 창을 잃기 때문).
