## 코디네이터가 독립적으로 재확인한 것

워커가 보고한 체크섬 핀은 그대로 믿지 않고 직접 받아 대조했다:

```
curl -fsSL https://raw.githubusercontent.com/tesseract-ocr/tessdata/4.1.0/eng.traineddata
wc -c    → 23466654
shasum -a 256 → daa0c97d651c19fba3b25e81317cd697e9908c8208090c94c3905381c23fc047
```

Dockerfile의 `ARG TESSDATA_ENG_SHA256`과 일치한다. 커밋 메시지도 Lore 형식을 따르고
에이전트 서명·세션 트레일러가 없음을 확인했다.
