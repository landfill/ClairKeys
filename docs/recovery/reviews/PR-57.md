## 원인과 수정

`pianoLayout.ts`는 왼쪽 흰건반의 절대 x에 옥타브 C 기준 절대 오프셋을 더했다. C#만 원점이
우연히 같았고 D#/F#/G#/A#은 각각 1/3/4/5칸 밀렸다. 오프셋을 왼쪽 흰건반 기준
`0.65/0.6/0.65/0.6/0.6`으로 바꾸고, 건반과 낙하 노트에 함께 남아 있던 `* 0.2`
렌더 보정을 양쪽에서 제거했다. `SimplePianoKeyboard`의 건반은 `KeyLayout.x`를 좌변으로 쓰고,
폭이 더 좁은 낙하 노트는 `keyPos.x + (keyPos.w - width) / 2`로 해당 건반에 중앙 정렬한다.

커밋 `299951d`의 “original asymmetric placement” 표현은 부정확하다. 원래 표와 현재 PR 값은
실제 피아노 비대칭이 아니라 거의 경계 중앙인 근사다. 실제 중심 편차는 C# -0.10, D# +0.10,
F# -0.15, G# 0.00, A# +0.15칸인 반면 현재 PR은 모두 -0.05~-0.10칸이다. 즉 D#/A#은
방향이 반대이고 G#은 실제로 경계 정중앙이다. 실제 좌변 오프셋 `0.611/0.806/0.563/0.709/0.854`와
검은건반 폭 0.583칸 적용, `PianoKeyboard.tsx`와의 통일은 이슈 #58로 분리했다. PR #57은
최대 5칸 밀리던 결함만 고친다.
