- 측정이 작업 자체를 두 번 바꿨고, 둘 다 기록한다. (1) 실패 상태 조건을 `loadError`만 보는
  대신 `loadError && 목록이 비어 있음`으로 좁혔다 — `useSheetMusic`의 `error`는 조회뿐 아니라
  수정·삭제 실패에도 설정되므로, 넓게 두면 제목 저장 실패가 "목록을 불러오지 못했습니다"로 잘못
  보고된다. 이 판단은 `keeps the list when the failure was a save, not a load`로 고정했다.
  (2) 빈 상태 판정식을 "문서 전체 높이 < 화면의 1.6배"에서 "빈 상태 카드 아래 공간 < 한 화면"으로
  바꿨다. 1.6은 근거 없는 배수였고 정상적인 머리글·탭까지 함께 셌다. 같은 빌드에서
  `min-h-screen`을 다시 넣어 등가 상태를 만들어 대조했다: 1116px(실패) → 687px(통과).
