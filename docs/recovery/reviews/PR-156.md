### The local file was backed up before pulling, and it mattered

Pulling this merge DELETES `.claude/settings.local.json` from the working tree, because the merge
removes a tracked file. The directory `.claude/` was removed along with it once it was empty. That
is not a side effect to discover afterwards: this session had already lost the user's edit to that
same file earlier today through the tracked-and-gitignored checkout trap.

So the file was copied outside the repository BEFORE the merge, and restored afterwards into a
recreated `.claude/`. The end state is the intended one and was verified:

- The file exists locally with its permission allowlist intact.
- `git check-ignore -v` reports `.gitignore:55` matching it.
- `git ls-files .claude/` returns 0 — nothing under `.claude/` is tracked any more.
- `git status` no longer lists the file or the eight ui-audit PNGs.

change. The permanently-uncommittable paths are gone from it, so AGENTS lifecycle rule 7 can clear
