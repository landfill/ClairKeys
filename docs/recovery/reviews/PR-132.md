1. **비용이 아니라 제약.** `makeCandidate`의 상대적 모양 비용은 지불 가능하므로, 다른 구간의 싼 전이들이
   불가능한 화음을 사올 수 있었다(`E4 + E5` → 4·5번). 후보 생성 시점에 쳐낸다.
2. **표는 셋째 자리에.** 계측이 모델의 표를 참조하면 순환이고, 복제하면 조용히 어긋난다. 해부학은 모델의
   판단이 아니므로 `src/utils/handReach.ts`에 두고 양쪽이 읽되 서로를 import하지 않는다.
