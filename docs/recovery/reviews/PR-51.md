## 범위

animation contract `1.0` → `1.1`. `tempo`가 nullable이 되고 `tempoSource`·
`timingReferenceBpm`·`scoreTempo`가 추가된다. `<beat-unit>` 환산, `/process`의 `tempo`
폼 필드, 업로드 폼의 선택 입력, 재생 화면의 출처별 표시.

파일 25개(fixture 8개 포함), 커밋 1개.

## 하나의 커밋으로 묶은 이유

WORKFLOW는 "한 커밋은 하나의 결정"을 요구한다. beat-unit 환산과 "120을 지어내지 않는다"는
표면적으로 두 결함이지만 **하나의 결정**이다 — 출처를 기록하는 일은 기록되는 값이 믿을 만할
때만 의미가 있고, 두 변경은 `_extract_tempo`/`_find_tempo`라는 같은 함수와 같은 출력 계약을
공유한다. 분리하려면 검증하지 않은 중간 상태를 만들어야 했다.

   인식되지 않는다(#48 잔여, 원인 미규명). 이 PR은 "들어오면 올바르게 환산"과 "안 들어오면
   지어내지 않음"만 보장한다.
2. 브라우저 왕복 미수행.
3. **이미 저장된 악보의 속도는 바뀌지 않는다** — 재변환이 필요하다.
