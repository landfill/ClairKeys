## 상세 문서의 후속 후보

이번 범위는 루트 README다. `docs/architecture.md`·`docs/limitations.md`·`docs/environment.md`·`omr-service/README.md` 등에 callback/최종 MusicXML·현재 연습 기능·설정 설명의 누락 또는 과거 설명이 남는다. `docs/testing.md`의 "E2E 하나·로그인 화면 미포함"도 현재 코드와 다르다. 관련 파일의 동작 변경이나 별도 문서 현행화는 하지 않고 현재 코드·복구 기록을 확인하도록 README에서 안내한다.

Supabase 공식 changelog와 Storage 다운로드 문서는 `.md` URL의 web 도구 content-type 오류 후 curl로 회수해 확인했다. 문서만 바꾸므로 Supabase 기능·schema·권한을 구현하지 않았고 운영 DB 질의도 하지 않았다. 현재 공개 JSON 제약과 서버 전용 키 배치를 코드·기존 Storage 가이드와 대조했다. [공식 changelog](https://supabase.com/changelog.md) · [Storage 다운로드](https://supabase.com/docs/guides/storage/serving/downloads).

구현 워커: Codex `gpt-6.1-sol`, high. README를 편집하고 보고서의 코드 원본·변경 범위·후속 후보를 위 표와 문단에 회수했다. 오케스트레이터가 원본 대조·최종 문서 보정·검증·Git·PR·상태 기록을 담당한다. 워커는 테스트·빌드·네트워크·DB 변경을 실행하지 않았다.
