# #134 남은 붙임줄 12개 원인 재분류 (2026-09-19)

## 범위

- 운영 PR169(`9e4020a`)와 같은 로컬 검증 이미지 `clairkeys-omr:d070b-patched`(`39381f8f…`)의 최종 Clair 실행
  `issue134-m3-duplet-2026-09-19/hardened-clair-1`(191/191·타이31/43·누락12·오검출0)의 저장 그래프(`.omr`)를 읽기만 했다.
- 코드 변경·엔진 재실행·VM 접근은 없다. 원본 페이지 crop과 분석 스크립트는 Git 제외
  `local-test-data/results/issue134-residual-ties-2026-09-19/`에 있다(`graph.py`, `trace.py`, `spaceclear.py`, `crop-*.png`).
- 2026-09-14 분류([tie-curves](2026-09-14-issue-134-tie-curves.md))는 누락20개 시점이었다. 이후 리듬 수정으로 음표 191/191이 되어
  "선행 리듬 오류 파생" 항목은 사라졌고, 남은 12개를 곡선 단위로 다시 대조했다.

## 방법

1. 머리 음높이: 음자리표·보표·변화표로 MIDI를 계산했다. 17마디 중 16마디의 (보표, MIDI) 집합이 기준표와 같았다.
   예외 m2 보표2 A4 1건은 마디선 근처 경계 판정 문제로, 대상 마디와 무관하다.
2. 누락 타이마다 시작 머리·다음 같은 음 머리·4 IL 안의 곡선과 `slur-head` 연결을 나열했다(`trace.py`).
3. 같은 보표 안 판정: 엔진 `SlurInter.checkStaffTie`(LINKS epilog)는 `areTieCompatible`와 `isSpaceClear`를 요구한다.
   `isSpaceClear`의 상자(두 머리 + 두 화음 기둥 끝)와 침범 비율(한도 0.25)을 저장 그래프로 재현했다(`spaceclear.py`).
   머리 core bounds 대신 머리 bounds를 사용했으므로 근사값이다.
4. 시스템 경계: `Part.getCrossSlurLinks`는 앞 시스템 끝 반쪽과 다음 시스템 시작 반쪽을 위에서부터 차례로,
   pitch position 차 4 IL 이내면 짝짓고 `checkCrossTie`가 두 머리의 음이 같을 때만 tie로 표시한다.
   저장 그래프의 `left-extension`/`right-extension` 속성이 실제 짝을 담고 있다.
5. 300dpi 원본 페이지 crop으로 인쇄된 곡선을 확인했다.

### E. 판정 상자 침범 3건

| 곡선 | 연결 | 상자 | 침범 화음 | 비율 |
|---|---|---|---|---|
| #4059 아래 | m9 E3 #1845 → E3 #1847 | (1898,1929,109,130) | C3 chord #3837 (1982,2008,24,63) | 0.39 |
| #4046 | m9 G3 #1823 → G3 #1825 | 같음 | 같음 | 0.39 |
| #3967 위 | m10 D5 #1891 → m11 D5 #1896 | (544,2271,283,118) | A4 chord #3844 (544,2338,24,64) | 0.43 |

- 침범 화음은 모두 **오른쪽(또는 왼쪽) 끝 머리와 같은 x에 선 다른 성부의 화음**이다.
  m9는 E3/G3 점2분과 같은 자리의 C3(아래 성부, 기준표상 공유 최저음), m10은 D5(기둥 위)와 같은 자리의 A4(기둥 아래) 점2분이다.
- 엔진은 양끝 화음과 mirror 머리의 화음만 제외하므로, 같은 시점의 이웃 성부 화음이 "사이에 낀 화음"으로 간주된다.
  기준 곡선 #4052(m9 E3 → E3, 같은 빔 그룹)는 상자 안에 다른 화음이 없어 tie로 판정됐다.
- crop 확인: m9 저음부는 E3/G3 8분에서 C3/E3/G3 점2분으로 두 붙임줄이 인쇄돼 있고, m10 D5 점 뒤 짧은 호가 m11 첫 D5로 이어진다.
- 2026-09-14 분류의 "slur 오분류 1"(m10)과 리듬 파생으로 보였던 m9 2건이 같은 기전이다.

- m6 E4: m7 첫머리 E4 위의 호가 다른 선보다 **옅은 회색**으로 인쇄돼 있고 검출되지 않았다. 아래의 #4016은 기준표 주석대로 이음줄 연속부다.
- m9 C5/E5: m9 끝의 렌즈 모양 중 **아래 호(C5)** 와 m10 첫머리의 **위 호(E5)** 가 없다. 남은 E5 앞 반쪽과 C5 뒤 반쪽이 서로 짝지어졌다.

미검출 반쪽은 오선에 붙은 호, 음자리표 옆의 작은 괄호 모양 호, 옅은 인쇄다. 반쪽이 없으면 tie가 성립할 수 없으므로
짝짓기 규칙만 고쳐서는 되살아나는 붙임줄이 없다. 반쪽들이 어느 단계에서 사라지는지는 이번에 추적하지 않았다.
