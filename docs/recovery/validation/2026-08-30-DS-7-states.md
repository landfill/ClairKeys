## 사용자 수동 체크리스트

### 조건 7 — 종단 여정

1. 로그아웃한 시크릿 창에서 홈에 진입한다. 히어로와 `내 악보로 시작하기`, `PDF → 변환 → 시각적 연습` 3단계를 본다.
2. 홈의 낙하 노트 결과 영역이 첫 화면에 확보되어 있는지 확인한다.
3. `내 악보로 시작하기`를 누른다. 로그인 화면의 세 가지 이유와 원래 행동 복귀가 보이는지 확인한다.
4. 로그인하고 업로드 화면으로 돌아온다. PDF 드롭존과 메타데이터 입력이 보이는지 확인한다.
5. PDF를 올리고 변환을 시작한다. 처리 단계와 `보통 1~3분` 안내가 보이는지 확인한다.
6. 처리 중 다른 페이지로 이동한다. 업로드 화면을 떠나도 처리가 계속된다는 계약을 확인한다.
7. `내 악보`에서 같은 곡을 찾는다. 완료 배지(연습 가능)가 표시되는지 확인한다.
8. 같은 곡의 연습 진입점을 누른다. 플레이어가 열리고 별도 안내 없이 재생·속도 조절 컨트롤이 보이는지 확인한다.
9. 재생을 한 번 실행한다. 낙하 노트와 피아노 반응이 시작되면 조건 7을 통과로 기록한다.

### 조건 4 — 실제 업로드 1회

1. 로그인한 상태에서 실제 PDF를 업로드하고 변환을 시작한다.
2. 업로드 직후 화면에 현재 처리 단계(예: PDF 분석, 음표 인식)와 예상 대기 시간(보통 1~3분)이 함께 표시되는지 확인한다.
3. 처리 중 페이지를 떠났다가 다시 들어와도 처리 상태가 유지되는지 확인한다.

### 조건 3 — 익명 공개 체험

1. 로그아웃한 시크릿 창에서 탐색으로 이동한다.
2. 공개 악보 카드를 선택해 상세 화면을 연다.
3. 상세 화면에서 로그인 없이 미리보기가 표시되는지 확인한다.
4. 재생을 누르고 실제 오디오와 낙하 노트가 시작되는지 확인한다.
5. 미리보기 후 로그인하고 같은 곡 상세로 복귀하는지 확인한다.
