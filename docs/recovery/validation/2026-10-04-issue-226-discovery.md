# Discovery — #226 연습 진도 범위 결정 전 조사

Date: 2026-10-04 KST
Baseline: main. 읽기 전용 코드 조사, 구현·DB 변경 없음.

## 확인된 기존 기능

- `prisma/schema.prisma`의 PracticeSession은 userId, sheetMusicId, durationSeconds, completedPercentage, createdAt을 저장한다.
- `src/app/api/sheet/[id]/practice/route.ts` GET은 현재 로그인 사용자의 한 곡 기록을 aggregate한다. POST는 접근 가능한 악보만 기록하고 사용자 ID는 세션에서 얻는다.
- `src/hooks/usePracticeReport.ts`는 재생 중인 실제 시간(일시정지/기다리기 대기 제외)과 도달한 최대 재생 위치를 기록한다.
  10초 미만은 저장하지 않는다. completedPercentage는 정확도·실력·레슨 완료가 아니라 최대 재생 위치다.
- 타인의 비공개 악보는 기록 조회/저장에서도 404다. 이후 접근 권한이 없어지면 기존 기록의 악보 존재도 드러내지 않아야 한다.
- 레슨 열람/완료 데이터 모델은 없다. 비로그인 레슨과 `/learn`은 공개 경로다.
- `src/lib/routeAccess.ts`가 인증 경로를 관리한다. 별도 기록 페이지를 보호하더라도 `/learn` 전체를 보호하면 안 된다.
- #227 정적 코스는 SheetMusic ID가 없어 기존 DB 기록에 포함되지 않는다. 코스 화면에서 계정에 저장되지 않는다고 명시한다.

## 사용자에게 전달한 선택지 (아직 답변 없음)

1. 권고: 로그인 사용자의 기존 곡별 연습 기록만 모음. 열람 기록/실력/레슨 완료 판정 없음.
2. 곡별 기록 + 레슨 열람 기록. 레슨 열람은 비로그인도 브라우저에 저장, 완료 판정 없음.
3. 곡별 기록 + 레슨 진도. 저장 방식·완료 기준 추가 결정 필요.

이슈 본문과 사용자의 goal 지시가 사용자 결정을 요구하므로, 답변 전 종속 구현을 진행하지 않는다.
#225·#227·#228의 독립 작업은 진행했다. 이 문서는 선택을 대신하는 새 계획이나 기술 결정이 아니다.

## 이후 검증에서 놓치면 안 되는 경계

사용자별 분리, 비공개 접근 상실, 비로그인, 기록 없음, 조회 실패, 기존 기록의 정확한 단위와 의미, 재생 도달률을 학습 완료로 오해하지 않는 표시.
범위가 정해지면 관련 phase·DECISIONS와 구현 브랜치에서 계획을 확정한다. 운영 DB migration은 별도 승인 대상이다.
