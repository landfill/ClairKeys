## 아바타 테스트가 실제 결함을 찾았다

처음 구현에서 전체 Jest가 **통과했는데 `tsc`가 실패**했다(`OptimizedImage`는 named export). 즉 아바타가
있는 경로를 **어떤 테스트도 타지 않고 있었다.** 테스트를 추가하자 이미지가 렌더되지 않았다 —
`OptimizedImage`는 `lazy = true`가 기본이라(`:38, 42, 85`) IntersectionObserver를 기다리는데, 프로필
아바타는 **페이지 최상단 요소**라 지연 로드할 이유가 없다. `priority` + `lazy={false}`로 고쳤다.
