# #226 내 연습 기록

Status: IN_PROGRESS
Date: 2026-10-04
Issue: https://github.com/landfill/ClairKeys/issues/226

## Objective and chosen scope

사용자가 2026-10-04 "1. 권장안"을 선택했다. 로그인 사용자의 기존 곡별 연습 기록(횟수·시간·최근 연습일·최고 재생 도달률)을 모아 보여준다.
비로그인 저장, 레슨 열람/완료 판정, 정적 코스의 계정 기록은 추가하지 않는다. 기존 PracticeSession 재사용, DB schema/migration 없음(D-098).

## Work stages

1. `/api/practice` GET의 인증·사용자별 분리·현재 악보 접근권한·페이지 조회 회귀 테스트.
2. 읽을 수 있는 악보의 현재 사용자 기록만 곡별 집계. 조회 시작 시각 이전 기록만 최근 연습순 20곡씩 cursor 조회, private/no-store 응답.
3. `/practice` 로그인 전용 화면: 곡별 횟수·총 재생 시간·최고 재생 위치·최근 연습일·곡으로 이동.
4. 배우기 홈에서 진입. `/learn` 공개성 유지, 재생 루트·헤더 메뉴는 변경하지 않는다.
5. 로딩·빈 상태·실패/재시도·페이지 이동·비로그인 접근 E2E 및 320px 화면 확인.

## Constraints

세션 userId를 기준으로 조회하며 요청의 사용자 ID를 받지 않는다. 공개를 해제한 타인의 악보는 기록에서도 숨긴다.
최고 %는 도달한 재생 위치이며 정확도·숙련도·레슨 완료 판정으로 표시하지 않는다. 계정 전환/이탈 시 이전 요청을 취소하고 이전 기록을 남기지 않는다.
10초 미만을 기록하지 않는 기존 쓰기 규칙은 변경하지 않는다. 운영 DB 변경/배포 없음.

## Completion criteria

위 기능과 인증·접근 경계 검증, 전체 로컬 테스트·CI·리뷰, 사용자 승인 후 병합·Post-merge·이슈 상태 일치.
