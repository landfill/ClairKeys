## Objective

#76은 대상 사용자를 악보를 거의 읽지 못하는 피아노 완전 초보자로 정했다. 지금 사이트는 PDF 변환과 떨어지는 음표 따라 누르기만
제공해, 초보자는 곡을 외워 칠 수는 있어도 건반·악보·손가락 번호를 이해하게 되지 않는다.
학습 콘텐츠는 새 `배우기` 영역의 페이지로 만들고, 재생 화면에는 치는 동안 필요한 최소 표시만 더한다.
사용자가 가져온 곡과 레슨은 곡 소개로 연결한다.

## 현재 (main `6d3bfb6`)

- 메뉴는 `내 악보`·`새 악보`·`탐색` 3개(`src/components/layout/Header.tsx`)이고 배우러 갈 곳이 없다.
- 초보자용 설명은 재생 화면(`FallingNotesPlayer`)의 "연습 방법" 3줄 목록과 단축키 안내가 전부다.
- 건반·음표 위 계이름 표시, 가운데 도 표시, 악보 기초·손가락 번호 설명이 없다.
- 재생 화면에는 재생·위치·A-B 반복·빠르기·양손/한 손·메트로놈·기다리기·악보 패널·이어서 연습·단축키가 이미 모여 있다.

## 화면 배치 원칙 (D-094)

| 위치 | 둘 것 | 두지 않을 것 |
|---|---|---|
| 재생 화면 | 치는 동안 보는 표시(계이름 토글, 가운데 도), 해당 레슨으로 가는 도움말 링크 | 여러 줄 설명, 레슨 본문, 연습 요령 목록 |
| `배우기` 페이지(로그인 불필요) | 치기 전·후에 읽고 익히는 내용, 인터랙티브 예시 | 실제 곡 재생기 전체 |
| 곡 소개 | 그 곡에 필요한 개념 요약과 레슨 링크 | 레슨 본문 복제 |

- 메뉴 순서: `배우기`·`탐색`·`내 악보`·`새 악보`. `/learn` 아래는 `isProtectedPath`에 넣지 않는다.
- 계이름은 C=도 고정(`도 레 미 파 솔 라 시`), 가운데 도는 C4(MIDI 60).
- 단계 지도 순서: 건반 → 악보 읽기 → 손 → 연습 방법. 아직 없는 레슨은 링크하지 않는다.

### 단계에 걸친 제약

1. **재생 화면 요소 수(L-3·L-5)**: 옮길 "연습 방법" 목록과 단축키 안내는 이미 재생 중에는 사라지고, 터치 화면에서는 재생 전에도
   단축키가 숨겨진다. 합계 비교로는 재생 중 화면이 더 복잡해지는 것을 막지 못한다. 세는 단위를 정의하고 데스크톱·터치에서
   재생 전·재생 중·일시정지 상태별로 이전/이후를 비교해 기록한다. 새 요소마다 재생 전에만 보이는지 밝히고,
   재생 중에 보이는 추가는 무엇으로 상쇄하는지 적는다. 회전 화면에서 건반 레인을 가리지 않는다.
   세는 것은 조작 요소와 설명 텍스트다(태그가 아니라 글자를 직접 가진 보이는 요소). 건반 안의 표시는 종류별로 따로 세고, 기본 꺼짐인
   계이름 표시가 켜졌을 때 늘어나는 수는 상쇄 대상이 아니라 기록 대상이다(D-094 6). 측정 spec: `e2e/playback-element-count.spec.ts`.
2. **곡 정보의 출처(L-6)**: `normalizeAnimationData`와 변환기는 박자가 없으면 `4/4`, 장·단조가 없으면 장조로 채운다.
   원본 근거가 있는 값만 보여 주고, 불확실한 값은 그렇다고 표시하거나 뺀다. 조표만으로는 나란한조를 구분할 수 없다.
3. **음표·쉼표 종류(L-6)**: `CanonicalNote`에는 쉼표·기보 종류 필드가 없고 변환기(`omr-service/omr/converter.py`)는 쉼표를 버리고
   붙임줄 음을 합친다. 기보 정보를 보존하는 계약이 생기기 전에는 음표 종류와 쉼표 종류를 표시하지 않는다(D-049/D-052).
4. **이론 설명의 근거(L-4·L-5)**: 용어·설명을 표준 교재 정의와 대조한 표(출처 포함)를 검증 기록에 남긴다.
   청취 판단은 완료 조건이 아니다.
5. **디자인**: 기존 디자인 토큰만 쓴다. 새 토큰을 추가하지 않는다(ROADMAP 화면 소유 범위).

## Completion criteria

이슈 #208과 같다.

- 로그인하지 않은 처음 방문자가 메뉴에서 `배우기`로 들어가 건반·악보·손가락 번호 기초를 순서대로 볼 수 있다.
- 재생 화면의 요소 수가 늘지 않는다(상태별 비교 기록).
- 내 곡의 소개에서 그 곡에 필요한 레슨으로 이동할 수 있다.
- 음악 이론 설명은 표준 교재 기준과 대조한 근거를 검증 기록에 남긴다.
