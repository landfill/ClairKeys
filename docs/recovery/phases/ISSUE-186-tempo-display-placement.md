# #186 재생 화면 빠르기 표시 위치

Status: IN_REVIEW
Date: 2026-09-28
Issue: https://github.com/landfill/ClairKeys/issues/186

## Objective

재생 화면의 빠르기 표시(`♩=69 (직접 입력)`, 악보 표기, 옅은 노트 범례)가 낙하 노트 레인·히트라인·건반·컨트롤 바를
어떤 화면에서도 가리지 않게 한다. 표시 내용은 그대로 보인다.

## 원인

- 재생 세션의 `TempoDisplay`는 `fixed top-16`(64px) pill이었다(`2ce5e38`: 재생 화면 높이를 바꾸지 않으려고 띄움).
  PR140에서 옅은 노트 범례도 이 pill 안으로 옮겼다.
- 모바일 세로 재생은 플레이어 루트를 `transform: rotate(90deg)`로 돌린다. transform이 있는 조상은 `fixed` 요소의
  containing block이 되므로 pill이 회전된 루트 기준 64px, 즉 컴팩트 바(56px)+여백(8px) 바로 아래 노트 레인 위에 놓인다.
  화면에서는 오른쪽 세로 띠로 보인다. 회전하지 않는 가로 화면도 뷰포트 64px 지점이라 레인 윗부분을 가렸다.
- 로컬 재현: 새 E2E에서 390×844·375×812(회전)·844×390(가로 터치) 겹침 25,536px², 1280×720은 겹치지 않음.

## 선택한 배치 (D-090)

1. 재생 중 빠르기 표시는 컴팩트 바 **아래 한 줄**(in-flow, `text-xs`, 20px)이다. 바 아래 8px 여백 자리에 들어가므로 추가 높이는 12px.
2. 회전하지 않는 세션 루트는 `min-h-[100dvh]` 대신 `height: 100dvh`다(악보 ON 세션은 이미 그랬다). `min-h`에서는 측정 래퍼가
   자신이 크기를 정하는 상자만큼 커지는 고정점에 머물러, 짧은 창에서 페이지가 넘쳤다(844×390에서 3px, 667×375에서 19px).
   이 상태에서 한 줄을 더하면 건반 아래가 화면 밖으로 밀리므로 함께 고친다.
- 컨트롤 바 안에 넣는 안은 채택하지 않았다: 가로 폰(844px, 시간·음량 숫자 표시)에서 바의 고정 요소가 이미 약 560px이라
  빠르기·악보 표기·범례가 들어가면 탐색 막대가 사라진다. 좁은 PC 창(<640px)은 격자 배치라 칸도 없다.
- 설정 화면 배치는 바꾸지 않는다.

- 빠르기·악보 표기·옅은 노트 범례는 재생 중에도 화면에 보인다.
