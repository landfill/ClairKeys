## #225 scope

- 네 레슨의 기존 정의를 짧게 요약하며 학습 단계 순서는 바꾸지 않는다.
- 오선·줄/칸·음자리표·덧줄·큰보표·가운데 도, 음표/쉼표 길이·점음표·박자표,
  손가락 번호·다섯 손가락 자리, 속도·한 손·구간 반복·기다리기·메트로놈을 다룬다.
- 새 이론 정의가 필요한 마디·세로줄은 표준 자료 대조 후 포함한다.
- 그룹별 바로가기와 의미 있는 제목·정의 목록을 사용한다. 별도 검색/저장/API는 도입하지 않는다.
- 기존 토큰·레이아웃을 사용하고 재생 화면은 수정하지 않는다(D-094).

## Constraints

사용자 미커밋 변경 보존, 원본 근거 없는 박자·조·운지 보충 금지, 운영 DB·배포 별도 승인.
#226의 재생 도달률을 실력·학습 완료로 해석하지 않는다. `/learn`의 공개 접근을 유지한다.
검증 범위는 AGENTS/D-088, 음악 자료의 한계와 검증 누락은 validation에 기록한다.

## Completion criteria

네 이슈의 완료 조건, 현재 head CI와 actionable review 해결, 사용자 승인 후 병합,
Post-merge checks 확인 및 이슈 종료·기록 일치를 모두 충족해야 DONE이다.
병합 승인을 기다릴 때는 검증된 PR과 남은 결정·제약을 제시한다.
