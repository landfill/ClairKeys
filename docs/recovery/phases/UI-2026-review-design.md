# UI-2026 — 운영 사이트 점검에서 나온 화면 정리

Status: `DONE` — PR #189 merged `c272c69` (2026-09-27~28, user-run merge after CI and review).
Base: 2026-09-27 main `3df9702`.

## Objective

2026-09-27 운영 사이트(비로그인, PC 1440×900·모바일 375×812) 점검에서 발견한 화면 문제 중
동작 계약을 바꾸지 않고 고칠 수 있는 디자인·문구 문제를 한 PR로 정리한다.
우선순위 결함(#185 샘플 로딩 표시, #186 모바일 빠르기 표시 가림, #187 API 지연, #188 운영 콘솔 로그)은
별도 이슈로 추적하며 이 phase에 포함하지 않는다.

## Findings addressed

1. 탐색의 `추천 악보`·`인기 악보`는 실제 추천·재생 수가 아니라 최신 목록을 잘라 쓴다. 공개 악보가
   3개일 때 같은 3곡이 세 번 반복되고, 근거 없는 "추천/인기"라는 이름을 붙인다.
2. 최신 악보 카드에만 `연습 시작 →`가 없다.
3. 검색 결과는 클릭 핸들러가 달린 `div`라 링크가 아니며, 레거시 gray/blue 팔레트·파란 스피너·파란
   포커스 링과 탐색 탭과 다른 남색 카테고리 배지를 쓴다.
4. 비로그인 사용자에게 `공개 설정: 내 비공개만` 필터와 `(공개: n, 비공개: n)` 통계가 보인다.
5. 재생 준비 화면의 안내문이 번호가 붙은 한 줄에 몰려 있고, 음량이 `음량 (master gain)`·`0.50` 같은
   개발용 표기로 보인다. 파랑/빨강 노트가 왼손/오른손이라는 설명이 없다.
6. 로그인하지 않고 `/library`에 가도 업로드 전용 문구 `악보를 맡기기 전에 로그인해 주세요`가 나온다.
   보호 경로 미들웨어가 `callbackUrl`에 같은 origin의 **절대 URL**을 넘기는데 로그인 화면이 경로만 받아
   `/`로 떨어뜨리므로, 로그인 후에도 원래 화면이 아니라 홈으로 돌아간다.
7. 없는 악보 오류 상태가 카드 안에 카드가 한 번 더 들어간 모양이고, 악보 정보 카드가 레거시 gray
   팔레트를 쓴다.
8. PWA manifest의 `theme_color`/`background_color`가 브랜드와 무관한 파랑/검정이다.

## Work stages

1. 각 finding의 회귀 테스트를 먼저 추가해 변경 전 실패를 기록한다.
2. D-080에 따라 탐색을 근거 있는 단일 `최근 공개된 악보` 목록으로 바꾸고 모든 카드에 같은 행동을 둔다.
3. 검색 결과를 탐색과 같은 링크 카드·디자인 토큰으로 맞추고, 비로그인 사용자에게 소유자 전용 필터를 숨긴다.
4. 재생 준비 화면 안내·음량 표기·손 색상 범례를 정리한다. 재생 엔진·기본 음량·노트 색상은 바꾸지 않는다.
5. 로그인 안내 문구를 돌아갈 경로에 맞추고, 악보 오류·정보 카드와 manifest 색상을 토큰에 맞춘다.
6. 단위·E2E·타입·lint·build와 실제 브라우저 PC/모바일 화면을 확인하고 validation에 기록한다.

## Completion criteria

- 공개 악보 목록에서 한 악보는 한 번만 보이고, 추천·인기라는 근거 없는 이름이 없다. 모든 카드가 링크이며
  `연습 시작 →`를 가진다.
- 검색 결과 카드가 `/sheet/<id>` 링크이고, 검색 화면에 legacy gray/blue 팔레트 클래스가 없다.
- 비로그인 사용자에게 공개 설정 필터와 비공개 통계가 보이지 않는다. 로그인 사용자는 기존과 같다.
- 재생 준비 화면의 음량은 `음량` 레이블과 백분율로 보이며 조절 동작·기본값은 같다. 손 색상 범례가 있다.
- 로그인 화면 제목이 업로드·내 악보·악보 연습·기타 경로에 맞는 문구다. 같은 origin의 절대 URL
  `callbackUrl`은 그 경로로 복귀하고, 다른 origin·scheme·userinfo는 계속 `/`로 거절한다.
- 관련 unit/E2E·타입·lint·build가 통과하고 PC·모바일 실제 화면 확인이 validation에 있다.
- 한 목적의 non-draft PR을 열고 CI·리뷰를 처리한다. 명시적 사용자 승인 전에는 병합하지 않는다.
